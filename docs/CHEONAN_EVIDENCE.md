# 천안 근거 원장 (Evidence Ledger)

ON-FARM 제안서에 쓸 수 있는 수치와, **아직 못 쓰는 수치**를 구분해 기록한다.
심사 항목 「데이터 이해·분석 20점」은 숫자를 많이 넣는 게 아니라
**출처와 한계를 아는지**를 본다. 확인 안 된 것을 확인된 것처럼 쓰면 그 자리에서 잃는다.

### 공모전 데이터의 한계 (반드시 병기)

26개 대회 중 **6개는 수상작 기록이 공란**이며, 그중 하나가 하필
「2024 천안시 농촌마을만들기 아이디어 공모전」이다.
따라서 "역대 수상작에 없다"가 아니라 **"공개된 수상 기록 173건 중에는 없다"** 로 써야 한다.

### ★계산 시 주의 — 실제로 틀렸던 지점

KOSIS CSV 한 행에 **농가 9,488(가구)** 과 **농가인구 21,433(명)** 이 나란히 있다.
처음 만든 도구가 '행에서 가장 큰 숫자'를 농가 수로 집어 **미참여율이 89.5%로 부풀려졌다.**
지금은 헤더에서 `농가 (가구)` 열을 이름으로 찾고, 값이 10만을 넘으면 거부한다.
`python tools/cheonan_gap.py --self-test` 로 이 회귀를 고정한다.

발표에서 **89.5% 라고 말하면 원자료를 아는 심사위원에게 즉시 반박당한다. 76.2% 가 맞다.**

## ⚠️ 미확인 — 확보 전까지 제안서에 쓰지 말 것

| 필요한 수치 | 왜 필요한가 | 확보 방법 |
|---|---|---|
| 천안시 경영주 연령 분포 | 전국 78.8%를 천안에 그대로 적용하는 것은 추정이다 | KOSIS 연령별 경영주 통계 |
| 천안 농가 평균 경지면적 | '소농' 규모를 수치로 말하려면 필요 | KOSIS `DT_1EA1015`(경지규모별 농가) |
| 오룡상생장터 운영 현황 | 검색으로 확인되지 않음 | 천안시청 확인 또는 삭제 |

### KOSIS 수동 확보 경로

자동 조회가 막혀 있다(302 리다이렉트 + JS 렌더링, 브라우저 정책 차단).
직접 받아 `data/cheonan/` 에 넣어야 한다.

**① 경지규모별 농가 — 통계표 확정**

<https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1EA1015>

```
항목: 농가(가구)      ← '농가인구' 아님. 이 선택을 틀리면 숫자가 2배로 부푼다
지역: 충청남도 천안시
시점: 최신
→ 다운로드 → CSV (셀병합 해제, 열 이름 포함)
```

**② 경영주 연령별 농가 — 통계표 번호 미확정**

시군구 단위 연령 분포는 **농림어업조사(표본)가 아니라 농림어업총조사(전수)** 쪽에 있을 가능성이 높다.
검색으로 표 번호를 확정하지 못했으므로 아래에서 직접 고른다.

<https://kosis.kr/search/search.do?query=%EA%B2%BD%EC%98%81%EC%A3%BC+%EC%97%B0%EB%A0%B9%EB%B3%84+%EB%86%8D%EA%B0%80>

```
왼쪽 '국내통계' → 통계조사명에서 「농림어업총조사」 선택
→ 행정구역(시군구) × 경영주 연령별 농가 표를 고른다
→ 지역: 충청남도 천안시 / 시점: 최신 → CSV
```

시군구 단위 연령 분포가 없으면 **그대로 두고 전국 78.8% 추정 표기를 유지한다.**
없는 것을 만들어 쓰는 것보다, 추정이라고 밝히는 편이 데이터 이해 항목에서 유리하다.

**받은 뒤**

```
python tools/cheonan_profile.py            # data/cheonan/ 의 CSV 를 전부 읽는다
python tools/cheonan_profile.py --self-test
```

`cheonan_profile.py` 는 열을 **헤더 이름으로** 고르고, 합계가 9,488(전체 농가)에서 크게
벗어나면 경고한다. 농가인구를 농가 수로 읽었던 실수를 같은 방식으로 막는다.

## 산출 결과 (2026-08-12 확정)

```
로컬푸드 미참여율 = (9,488 − 2,256) / 9,488 = 76.2%  → 7,232가구
그중 경영주 60대 이상 추정 = 7,232 × 78.8% ≈ 5,700가구  (전국 비율 적용)
```

**천안 농가 4곳 중 3곳이 로컬푸드 체계 밖에 있다.** 이 한 줄이 제안의 근거다.

**주의**: 2,256곳은 '참여 농가' 이고 전체 농가 수와 조사 기준·시점이 다를 수 있다.
같은 기준으로 비교할 수 없으면 "단순 비교"임을 밝히고 범위로 제시한다.

## 논지에 쓰는 방식

천안은 로컬푸드에 이미 잘 투자했다(12곳·271억). 그래서 ON-FARM 은 그것과 **경쟁하지 않는다.**
로컬푸드 직매장은 정의상 **지역 내 소비** 모델이고, 농가가 **직접 갖다 놓고 가격표를 붙이고
재고를 관리**해야 한다. 여기서 두 개의 공백이 생긴다.

1. **직매장에 갈 수 없는 농가** — 고령·소농·거동 제약. (미참여율로 규모를 제시)
2. **지역 밖 수요** — 직매장 매출 상한은 천안 인구에 묶인다.

ON-FARM 은 이 둘을 겨냥한다. 직매장은 경쟁자가 아니라 **거점 인프라**로 편입된다.
