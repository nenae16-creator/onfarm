# 천안 근거 원장 (Evidence Ledger)

ON-FARM 제안서에 쓸 수 있는 수치와, **아직 못 쓰는 수치**를 구분해 기록한다.
심사 항목 「데이터 이해·분석 20점」은 숫자를 많이 넣는 게 아니라
**출처와 한계를 아는지**를 본다. 확인 안 된 것을 확인된 것처럼 쓰면 그 자리에서 잃는다.

### 공모전 데이터의 한계 (반드시 병기)

26개 대회 중 **6개는 수상작 기록이 공란**이며, 그중 하나가 하필
「2024 천안시 농촌마을만들기 아이디어 공모전」이다.
따라서 "역대 수상작에 없다"가 아니라 **"공개된 수상 기록 173건 중에는 없다"** 로 써야 한다.

### ★계산 시 주의 — 실제로 틀렸던 지점

KOSIS CSV 한 행에 **농가 9,488(가구)** 과 **농가인구 21,433(명)** 이 나란히 있다.
처음 만든 도구가 '행에서 가장 큰 숫자'를 농가 수로 집어 **미참여율이 89.5%로 부풀려졌다.**
지금은 헤더에서 `농가 (가구)` 열을 이름으로 찾고, 값이 10만을 넘으면 거부한다.
`python tools/cheonan_gap.py --self-test` 로 이 회귀를 고정한다.

발표에서 **89.5% 라고 말하면 원자료를 아는 심사위원에게 즉시 반박당한다. 76.2% 가 맞다.**

### ★78.8% 를 잘못 폐기했다가 되살렸다 (2026-08-13)

한동안 「전국 농가 경영주 60대 이상 **78.8%**」를 싣다가, **출처를 확인할 수 없다는 이유로
폐기했다. 그 폐기가 틀렸다.** 78.8% 는 실재하는 최신 공식 수치다.

| | 값 | 출처 |
|---|---|---|
| **전국 경영주 60대 이상** | **78.8%** (70대 이상 44.1%) | **2025 농림어업총조사 잠정**(기준일 2025-12-01, 2026-04-28 공표) |
| 전국 경영주 평균 연령 | **67.7세** (2020년 66.1세) | 〃 |
| 전국 농가 | 124.2만 가구 (2020 대비 +20.7만) | 〃 |
| (대조) 전국 경영주 60대 이상 | 73.3% | 2020 농림어업총조사 `DT_1AG20107` |

**왜 틀렸나 — 방법의 실수다.** KOSIS 통계표만 뒤졌다. KOSIS 에 2025 총조사 표가 없는 것은
사실이고(시군구 표는 **2026년 12월** 공표 예정), 거기서 "2025 값은 없다"로 건너뛰었다.
그런데 **잠정 결과 보도자료는 2026-04-28 에 이미 나와 있었다.**

> 통계표가 없다는 것과 수치가 없다는 것은 다르다. 총조사·인구조사류는 표보다 먼저
> 잠정 결과가 보도자료로 공표된다. 앞으로 "없다"고 결론 내리기 전에 보도자료를 확인한다.

전국이 2020년 73.3% → 2025년 78.8% 로 **5.5%p 올랐다.** 이 사실이 천안 수치의 성격을 바꾼다.

### 천안 70.0% 는 '하한'으로 쓴다

천안 실측 70.0% 는 **2020년** 값이다. 2025년 천안 값은 시군구 표가 나오는 2026년 12월까지 없다.
같은 기간 전국이 +5.5%p 올랐으므로 **천안의 2025년 실제 값은 70.0% 보다 높을 가능성이 크다.**

따라서 이렇게 쓴다.

- **천안 70.0%(2020 총조사, 실측)를 제시하고 "이후 고령화가 진행돼 지금은 더 높을 것"을 병기한다.**
- 전국 78.8%(2025 잠정)는 **추세를 보여주는 대조값**으로만 쓰고, 천안에 곱하지 않는다.
- 천안에 곱하는 비율은 천안 실측 70.0% 뿐이다.

전국값을 천안에 곱하던 예전 방식으로 돌아가지 않는다. 그건 여전히 틀린 방법이다.

### 확보 경로 (2026-08-12 완료)

브라우저 다운로드 대신 **KOSIS OpenAPI** 로 받았다. 표에 천안이 있는지를 받기 전에
확인할 수 있고, 명령 한 줄로 재현되기 때문이다.

어느 표가 시군구를 주는지부터 정리한다 — 여기서 두 번 헛짚었다.

| 표 | 이름 | 지역 레벨 | 천안 |
|---|---|---|---|
| `DT_1EA1015` | 경지규모별 농가 (농림어업조사·표본) | 시도까지 | ❌ |
| `DT_1EA1019` | 경영주 연령별 농가 (농림어업조사·표본) | 경지규모별 분해, 지역 아님 | ❌ |
| **`DT_1AG20107`** | **경영주 연령 및 교육정도별 농가 (농림어업총조사·전수 2020)** | **시군구 3,381종** | **✅ 34010** |

`DT_1AG20107` 한 표 안에 연령·교육정도·경지규모·판매금액·영농형태가 모두 들어 있어
경지규모까지 같은 표에서 얻었다.

```
$env:KOSIS_API_KEY = "발급받은키"
python tools/kosis_api.py probe DT_1AG20107 --prd F --obj1 34010 --obj2 ALL
python tools/kosis_api.py fetch DT_1AG20107 --prd F --obj1 34010 --obj2 ALL
python tools/kosis_api.py fetch DT_1AG20107 --prd F --obj1 00    --obj2 ALL   # 전국 대조
python tools/cheonan_age.py
```

인증키는 <https://kosis.kr/openapi/index/index.jsp> 에서 무료로 즉시 발급된다.
**키는 환경변수로만 넘긴다 — 코드·문서·저장소에 남기지 않는다.**

`objL1=ALL` 은 총조사처럼 큰 표에서 40,000셀 제한에 걸린다. 지역 코드를 직접 준다(천안시 `34010`).

## 산출 결과 (2026-08-12 확정)

```
로컬푸드 미참여율 = (9,488 − 2,256) / 9,488 = 76.2%  → 7,232가구      (2024)
천안 경영주 60대 이상 = 7,773 / 11,111 = 70.0%                        (2020 총조사)
천안 경지 1ha 미만    = 8,524 / 11,111 = 76.7%                        (2020 총조사)
그중 60대 이상 추정   = 7,232 × 70.0% ≈ 5,100가구
```

**천안 농가 4곳 중 3곳이 로컬푸드 체계 밖에 있다.** 이 한 줄이 제안의 근거다.
그리고 그 농가들은 **평균 65.1세가 경영하는, 경지 1ha 미만의 소농**이다.

**주의 세 가지** — 발표에서 먼저 말한다.

1. 2,256곳은 '참여 농가'로 전체 농가와 조사 기준·시점이 다르다. 정밀 차집합이 아니라 규모 감각이다.
2. 농가 수는 2024년, 연령·경지 비율은 2020년 총조사다. **연도가 다르다.**
3. 5,100가구는 참여 여부와 연령이 무관하다는 가정 위의 값이다. 실제로는 참여 농가가 더 젊을
   가능성이 높아 **보수적인 하한**으로 본다.

`python tools/cheonan_age.py` 로 위 계산이 그대로 재현된다(`--self-test` 로 열 선택 고정).

## 논지에 쓰는 방식

천안은 로컬푸드에 이미 잘 투자했다(12곳·271억). 그래서 ON-FARM 은 그것과 **경쟁하지 않는다.**
로컬푸드 직매장은 정의상 **지역 내 소비** 모델이고, 농가가 **직접 갖다 놓고 가격표를 붙이고
재고를 관리**해야 한다. 여기서 두 개의 공백이 생긴다.

1. **직매장에 갈 수 없는 농가** — 고령·소농·거동 제약. (미참여율로 규모를 제시)
2. 그 농가의 물건이 **어디에도 올라가지 못한 채 남는 것** — 사진 한 장이 상품이 되지 못한다.

ON-FARM 은 이 둘을 겨냥한다. 직매장은 경쟁자가 아니라 **거점 인프라**로 편입된다.

**수요는 겨냥하지 않는다.** 지자체 자사몰이 안 되는 이유는 상품이 없어서가 아니라 소비자가
쿠팡에서 사기 때문이다(`docs/FIELD_NOTES.md`). 등록 장벽 제거는 **필요조건이지 충분조건이 아니며**,
실제로 팔리는지는 8주 실증의 판매 성사율 50% 로 잰다.
