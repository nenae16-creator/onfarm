# 천안 근거 원장 (Evidence Ledger)

ON-FARM 제안서에 쓸 수 있는 수치와, **아직 못 쓰는 수치**를 구분해 기록한다.
심사 항목 「데이터 이해·분석 20점」은 숫자를 많이 넣는 게 아니라
**출처와 한계를 아는지**를 본다. 확인 안 된 것을 확인된 것처럼 쓰면 그 자리에서 잃는다.

### 공모전 데이터의 한계 (반드시 병기)

26개 대회 중 **6개는 수상작 기록이 공란**이며, 그중 하나가 하필

따라서 "역대 수상작에 없다"가 아니라 **"공개된 수상 기록 173건 중에는 없다"** 로 써야 한다.

## ⚠️ 미확인 — 확보 전까지 제안서에 쓰지 말 것

| 필요한 수치 | 왜 필요한가 | 확보 방법 |
|---|---|---|
| **천안시 전체 농가 수** | 2,256곳이 전체의 몇 %인지 모르면 "직매장 밖 농가가 많다"는 주장이 성립하지 않는다. **이 논지의 핵심 근거** | KOSIS 수동 다운로드(아래) |

| 천안 농가 평균 경지면적 | '소농' 규모를 수치로 말하려면 필요 | KOSIS `DT_1EA1015`(경지규모별 농가) |
| 오룡상생장터 운영 현황 | 검색으로 확인되지 않음 | 천안시청 확인 또는 삭제 |

### KOSIS 수동 확보 경로

자동 조회가 막혀 있다(302 리다이렉트 + JS 렌더링, 브라우저 정책 차단).
직접 받으셔야 한다.

```
kosis.kr → 국내통계 → 주제별통계 → 농림어업 → 농림어업조사 → 농업
  → 「행정구역(시군구)별 농가, 농가인구」  (통계표 ID: DT_1EA1011)
  → 항목: 농가수 / 지역: 충청남도 천안시 / 시점: 최신
  → 다운로드(CSV)
```

경지규모는 같은 경로에서 `DT_1EA1015`(경지규모별 농가)를 받는다.
받은 CSV 를 `data/cheonan/` 에 두고 `tools/cheonan_gap.py` 를 실행하면 아래 지표가 계산된다.

## 계산할 지표 (데이터 확보 후)

```
로컬푸드 미참여율 = (천안 전체 농가 − 2,256) / 천안 전체 농가
```

이 한 줄이 ON-FARM 제안의 근거가 된다.
예: 전체 8,000가구라면 **71.8%가 로컬푸드 체계 밖**이라는 뜻이다.

**주의**: 2,256곳은 '참여 농가' 이고 전체 농가 수와 조사 기준·시점이 다를 수 있다.
같은 기준으로 비교할 수 없으면 "단순 비교"임을 밝히고 범위로 제시한다.

## 논지에 쓰는 방식

천안은 로컬푸드에 이미 잘 투자했다(12곳·271억). 그래서 ON-FARM 은 그것과 **경쟁하지 않는다.**
로컬푸드 직매장은 정의상 **지역 내 소비** 모델이고, 농가가 **직접 갖다 놓고 가격표를 붙이고
재고를 관리**해야 한다. 여기서 두 개의 공백이 생긴다.

1. **직매장에 갈 수 없는 농가** — 고령·소농·거동 제약. (미참여율로 규모를 제시)
2. **지역 밖 수요** — 직매장 매출 상한은 천안 인구에 묶인다.

ON-FARM 은 이 둘을 겨냥한다. 직매장은 경쟁자가 아니라 **거점 인프라**로 편입된다.
