# 활용 데이터 명세

공고문 「데이터 활용 기준」이 요구하는 항목을 데이터별로 적는다.

> 정식 API 또는 공공 포털 등을 통해 합법적으로 수집한 데이터만 허용
> **수집 시점, 범위, 주요 컬럼(변수) 등 기술 필수**
> **제안서 내 활용 데이터 명확히 명시, 출처(URL 포함) 반드시 기재**
> 제3자의 라이선스를 침해하거나 상업적 목적의 민간 데이터 무단 사용은 엄격히 금지됨

## 1. 모델 학습 데이터

### AI Hub 「농산물 품질(QC) 이미지」

| 항목 | 내용 |
|---|---|
| 출처 | <https://aihub.or.kr/> · 데이터셋 번호 **149** |
| 수집 시점 | 2026-08-09 ~ 08-10 (aihubshell 내려받기) |
| 구축·갱신 | 2020 구축 / 2023-09 갱신 |
| 전체 규모 | 정제 30만 건 · 224 GB (원천 PNG + 분류 라벨 JSON) |
| **실제 사용 범위** | **5개 품목**(사과·배·감귤·감자·양파) · 학습 이미지 122,425장 |
| 주요 변수 | `품목`, `품종`, `등급`(특·상·보통), `중량`, `group_no`(개체 식별자), 이미지 파일 |
| 이용 조건 | 내국인 회원가입 + **데이터셋별 다운로드 승인 필요**. 승인 후 내려받았다 |
| 라이선스 표기 | 제공처 표기 "직접 촬영한 데이터로 라이선스 없음" |

**분할 방식 — 이 데이터의 핵심 주의사항**

같은 물체를 여러 각도로 촬영한 데이터라 **이미지 단위로 나누면 같은 개체가 학습·검증
양쪽에 들어가 성능이 부풀려진다.** 그래서 `group_no`(개체) 단위로 분할했다.

| 구분 | 개체 수 |
|---|---|
| 학습 | 1,056 |
| 검증 | 201 → 중복 1건 제거 후 **200** |
| 겹친 개체 | **1건**(`602132129000`) — 검증에서 제외 |

성능 수치는 전부 **개체 단위**로 계산했다. 이미지 단위 수치는 쓰지 않는다.

**한계 (제안서·발표에 함께 적는다)**

- 흰 배경·균일 조명의 **스튜디오 촬영**이다. 밭에서 찍은 휴대폰 사진과 다르다.
- 따라서 `models/metadata.json` 의 `field_evaluated` 는 `false` 이며,
  실환경 평가 전까지 신뢰도가 0.85 를 넘지 못하도록 코드가 막는다.

통계 원자료가 아니라 **언론 보도**다. 시 공식 집계와 기준·시점이 다를 수 있어
전체 농가 수와의 비교는 정밀한 차집합이 아니라 **규모 감각**으로 제시한다.

## 4. 서비스가 생성하는 데이터 (제출물에 포함되지 않음)

농가가 등록 시 올리는 사진과 등록·주문 기록은 **서버 안에서만 처리**되며 외부 API 로
전송되지 않는다. 제출물에는 실제 농가 사진·개인정보가 일절 포함되지 않는다.
시연 화면의 사진은 위 AI Hub 검증 분할 이미지이고, 시드 상품 그림은 일러스트로
화면에 "일러스트 · 실제 사진 아님" 이라고 표기된다.

## 재현 방법

```
python tools/cheonan_gap.py --kosis data/cheonan/KOSIS_DT_1EA1011_충청남도_천안시_2024.csv
python tools/cheonan_age.py
python tools/kosis_api.py fetch DT_1AG20107 --prd F --obj1 34010 --obj2 ALL   # 원자료 재수집
```

각 스크립트에 `--self-test` 가 있고, 열·항목을 이름으로 고르는지 검사한다.
